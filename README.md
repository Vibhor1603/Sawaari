# 🛺 **Sawaari – Because India Moves on Auto Rickshaws**

Sawaari is more than just a project — **it’s a movement**.  
Born from my own everyday commute in sharing autos, I realized how convenient they are:  
✅ Fast ✅ Affordable ✅ Deeply rooted in Indian roads.

But there’s one glaring gap:

-   ❌ No centralized, reliable data exists for auto rickshaw routes.
    
-   ❌ Google Maps shows buses, metros & trains — but **not autos**, the **soul of Indian transport**.
    

----------

## 💡 **Why I Built Sawaari**

Every day I wished for one thing:

> “If I could see where sharing autos go — I could travel better.”

So I built **Sawaari** — a platform that makes **auto travel smarter, simpler, and more connected** for everyone.

----------

## 🔍 **What Problems Does Sawaari Solve?**

### 📍 1. Explore Auto Stands

-   View all auto rickshaw hotspots in your area.
    
-   Tap any stand to:
    
    -   See all reachable destinations from there.
        
    -   Get estimated **fare** and **travel time**.
        

----------

### 🗺️ 2. Auto Route Planner (Like Metro)

-   Enter your **source** and **destination**.
    
-   Sawaari will:
    
    -   Suggest optimal **sharing auto routes**.
        
    -   Show where to **change autos**, total **fare**, and complete **route map**.
        

----------

### 🧑‍🤝‍🧑 3. Find a Ride Buddy (Private Autos)

-   Want to split fare for a **private auto**?
    
-   Set a **radius** (e.g. 2km) to find people nearby going the same way.
    
-   View route **overlap %**, send **requests**, **chat**, and even **call via WhatsApp**.
    

----------

### 🔐 4. Secure Auth

-   Safe and working:
    
    -   ✅ Sign up
        
    -   ✅ Login
        
    -   ✅ Forgot password
        
    -   ✅ Reset password  
        All fully backend-validated.
        

----------

### 💬 5. Auto Gyaan

-   Learn **fun and fascinating facts** about Indian auto rickshaws — bite-sized and quirky.
    

----------

## 🧑‍💻 **Sawaari Admin Portal**

Built for **admin use only**:

-   🧾 Minimalist UI for adding/editing hotspots.
    
-   📄 Upload JSON or PDF to auto-fill hotspot data.
    
-   ✅ Ensures **data consistency** with existing MongoDB structure.
    

----------

## ✨ **Why It Matters**

🚕 **Auto rickshaws are the heart of Indian commuting** — yet completely missing from digital navigation.

Sawaari brings **structure**, **visibility**, and **accessibility** to a system that already works — just not online.  
This is just the **beginning**.
